# ✈️ Venta de Viajes - Dynamic Landing Page

Una aplicación web interactiva para la exploración y simulación de venta de paquetes turísticos. Este proyecto demuestra el uso avanzado de Vanilla JavaScript para la manipulación dinámica del DOM sin necesidad de frameworks externos.

🔗 **[Ver Demo en Vivo]([TU-LINK-AQUI])**

## 🚀 Características Principales

* **Renderizado Dinámico:** Actualización de la interfaz de usuario en tiempo real al seleccionar diferentes destinos.
* **Manipulación del DOM:** Uso eficiente de `getElementById`, `querySelector` y colecciones de nodos para modificar estructura y contenido.
* **Gestión de Eventos:** Implementación de Event Listeners para manejar la interacción del usuario de forma fluida.
* **Estructura de Datos:** Separación de la lógica de negocio y los datos (objetos de ciudades) para un código más limpio y escalable.

## 🛠️ Tecnologías Utilizadas

* **Vanilla JavaScript (ES6+)**
* **HTML5**
* **CSS3**

## 🧠 Aprendizajes y Retos Técnicos
El enfoque principal de este proyecto fue dominar los fundamentos de JavaScript en el navegador, asegurando un bajo acoplamiento entre los datos (almacenados en `ciudades.js`) y la capa de presentación.
